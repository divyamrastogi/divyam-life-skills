# Website Colour Palettes (proven combos)

When the user asks to design a website, propose one of these three palettes as the starting point. Pick based on the brand mood; offer the others as alternatives.

## Palette 1 — Bold Contrast (tech, creative, brands that want intensity)
- Base: **Midnight Navy** `#021861`
- Primary: **Cobalt Blue** `#255DCE`
- Accent: **Bright Red** `#DE1110`
Mood: strong foundation with high-intensity contrast. Use navy as the foundation, cobalt for primary actions/hero, red sparingly for CTAs and highlights. Pairs beautifully with rich organic imagery.

## Palette 2 — Editorial Earth (studios, portfolios, heritage, calm authority)
- Base: **Charcoal** `#090907`
- Primary: **Earth Brown** `#6C5636`
- Accent: **Burnt Amber** `#899D73`
Mood: grounded, warm, editorial. Dark charcoal canvas, earth-brown surfaces/text, burnt-amber highlights. Works with landscape photography and serif display type.

## Palette 3 — Timeless Elegance (design studios, art, luxury, bold minimal)
- Base: **Ink Black** `#031211`
- Primary: **Warm Ivory** `#E8E4D3`
- Accent: **Electric Teal** `#00AEBB`
Mood: timeless elegance that electrifies. Ivory on ink-black with teal accents — high contrast, gallery feel, works with illustrative/botanical art.

## How to apply
1. Present the chosen palette as CSS custom properties (bg, primary, accent) plus a suggested role for each colour.
2. Combine with `interface-design-rules` and `taste-skill` when available.
3. Only suggest these palettes when the user asks for website design — otherwise stay out of colour choices.

# charles-unslop

Turns AI-looking UI into a designed interface with one real idea.

## Install

Run this in your project:

```bash
npx skills add LemonFace0309/charles-skills --skill charles-unslop
```

Add `-g` to install it for every project. Then start a new session and ask for it:

```text
/charles-unslop this login page
```

Codex uses `$charles-unslop` instead of the slash. To install by hand, and to see my other skills, read the [main README](../../README.md).
